# Security Policy

## Supported versions

Security fixes are provided for the latest published version of Ops Agent.

## Reporting a vulnerability

Do not open a public Issue containing exploit details, credentials, kubeconfig
data, cluster addresses, or sensitive logs.

Use GitHub's private vulnerability reporting form:

<https://github.com/Chengyunlai/ops-agent/security/advisories/new>

Include the affected version, capability, reproduction conditions, security
impact, and the smallest possible redacted evidence. The maintainer will
acknowledge the report before requesting any additional sensitive material.
