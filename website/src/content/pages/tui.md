Ops Agent 在宽终端使用左右布局：左侧是确定性资源监盘和人工操作，右侧是多轮诊断对话。窄终端自动切换为上下布局，两侧数据不做隐式联动。

## 常用快捷键

| 按键          | 操作                               |
| ------------- | ---------------------------------- |
| `Ctrl+K`      | 聚焦左侧监盘                       |
| `0`           | 返回资源总览                       |
| `1`～`7`      | 切换常用资源                       |
| `↑` / `↓`     | 移动选择                           |
| `Enter` / `h` | 查看 Finding 与 Evidence           |
| `d`           | 查看资源详情与 Event               |
| `l`           | 打开 Pod 日志工作台                |
| `f`           | 浏览 PVC 目录；日志页中切换 Follow |
| `x`           | 进入人工 Pod Shell                 |
| `i`           | 聚焦对话输入                       |
| `?`           | 打开帮助                           |
| `Esc` / `q`   | 退出或关闭当前视图                 |

## 资源监盘

总览列出 Pod、Deployment、StatefulSet、DaemonSet、Service、ReplicaSet、Job、CronJob、Ingress 和 PVC 数量，并展示稳定的健康状态和原因。

Pod 表可以显示 AGE、重启、节点以及可选 CPU/Memory。刷新时会按稳定资源身份恢复选择，不会无条件跳回第一行。

## 日志工作台

日志可以按单个或全部容器读取，并限制为最近 200、500、1000 行或最近 15 分钟、1 小时。长行支持换行、视口截断和完整水平查看。

按 `/` 搜索，`n` 与 `Shift+N` 在匹配之间移动。日志聚焦可隐藏操作员明确选择的噪声，但不删除原始快照。

选择单个容器后，按 `f` 开始或停止只读 Log Follow。Follow 缓冲达到 10,000 条时会安全停止并明确提示，不会静默丢弃已显示证据。

## PVC 与文件下载

PVC 视图展示 PVC、PV、StorageClass、后端和挂载 Pod 关系。目录浏览复用已有挂载 Pod，只预览普通文本文件。

下载直接流式写入配置的本机目录，使用 `.part` 临时文件和原子发布。已有同名文件不会覆盖；完成后显示路径、大小与 SHA-256。

## 人工 Pod Shell

Pod Shell 默认关闭。开启后必须选择 Pod、容器并确认风险，随后 TUI 把终端控制权交给本机 `kubectl exec` 会话。

会话中的命令由操作员直接执行，不经过 AI。输入 `exit` 或按 `Ctrl+D` 返回 TUI；`download <文件>` 可把当前容器中的文件保存到受限本机目录。
